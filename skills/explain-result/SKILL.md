방금 자신이 낸 답변(명령어, 코드, 계획, 진단)을 사용자가 이해하지 못했을 때, 그것을 실행하면 무슨 일이 생기는지 설명한다. 서론 없이 시작한다.

설명 대상은 **직전 답변**이다. `/explain-result` 뒤에 특정 부분이 붙어 있으면 그 부분만 설명한다. 애매하면 되묻지 말고 가장 최근 답변의 핵심 하나를 고른다 — 되묻는 것 자체가 이 스킬의 목적(빨리 이해시키기)에 어긋난다.

## 먼저 현재 상태를 확인한다

"지금은 이렇다"를 추측으로 말하면 설명이 틀린다. 읽기만 하는 확인은 해도 된다: 파일 읽기, `git status`, `git diff`, `ls`, 설정 파일 확인, 버전 확인. 확인한 것만 말하고, 확인하지 못한 것은 "확인 못 함"으로 남긴다.

파일을 고치거나, 무언가를 설치하거나, 제안한 명령을 실제로 실행하지는 않는다. 이 스킬은 말로 설명하는 역할만 한다.

## 출력 형식

이 네 덩어리로만 쓴다. 각각 1~3문장.

**지금** — 확인한 실제 상태. "지금 이 프로젝트에는 로그인 화면이 없다.", "지금 members 표에는 이름과 전화번호만 있다."

**실행하면** — 그 답변대로 했을 때 컴퓨터가 하는 일. 명령어 이름이 아니라 하는 일로 말한다. "새 칸 하나를 표에 추가한다."

**그러면 이렇게 된다** — 실행 후 달라지는 것. 사용자 눈에 보이는 변화 기준으로 말한다. "회원 정보 화면에 메모 칸이 하나 더 생긴다. 기존 회원 정보는 그대로 남는다."

**결과값** — 실제로 화면에 뜰 것. 짧으면 그대로 보여준다.

```
✔ migration applied  (표 구조 변경 완료라는 뜻)
```

**되돌리기** — 이 줄은 되돌릴 수 없는 일(데이터·파일 삭제, 덮어쓰기, 배포, 외부로 보내기, 돈 나가는 일)이 실제로 섞여 있을 때만 쓴다. 안전하면 아예 쓰지 않는다 — "안심시키려고" 붙이지 않는다. 이 줄이 안전한 명령에도 붙기 시작하면 사용자가 그냥 넘기게 되고, 정작 위험한 명령에서 눈에 띄지 않는다.

## 규칙

- **짧게.** 네 덩어리를 다 합쳐 10문장을 넘기지 않는다. 사용자는 지금 이해가 안 돼서 답답한 상태다. 길면 더 답답해진다.
- **묻지 않은 것은 말하지 않는다.** 배경 지식, 대안, 더 나은 방법, 역사, 원리는 설명하지 않는다. 사용자가 따로 물으면 그때 답한다.
- **용어는 처음 한 번만 괄호로 푼다.** "migration(표 구조를 바꾸라는 지시서)". 두 번째부터는 그냥 쉬운 말로 쓴다.
- **비유는 필요할 때만 하나.** 구조가 실제로 비슷한 것에만 빗댄다. 비유가 어긋나는 부분이 있으면 "완전히 같지는 않지만"으로 짚는다.
- **쉽게 말하되 틀리지 않는다.** 정확도를 깎아서 쉬워지면 안 된다. 모르면 "여기는 실행해 봐야 안다"고 말한다.
- **평가하지 않는다.** 이 방법이 좋다/나쁘다는 말하지 않는다. 물어보면 답한다.
- 사용자가 쓰는 언어로 답한다. 기본은 한국어.

## 예시

**안전한 경우 — `되돌리기` 없음**

사용자: "npm run db:push 하라는 게 무슨 말이야?"

> **지금** — `schema.ts`(DB 설계도) 파일에는 메모 칸이 적혀 있지만, 실제 데이터베이스에는 아직 그 칸이 없다.
>
> **실행하면** — 설계도와 실제 데이터베이스를 비교해서, 빠진 칸을 실제로 만들어 준다.
>
> **그러면 이렇게 된다** — members 표에 `note` 칸이 하나 생긴다. 기존 회원 데이터는 지워지지 않고, 새 칸만 빈칸으로 붙는다. 이후 회원 화면에서 메모 저장이 동작한다.
>
> **결과값**
> ```
> [✓] Changes applied
> ```

칸을 추가하기만 하고 지워지는 것이 없으므로 `되돌리기` 줄을 붙이지 않는다.

**되돌릴 수 없는 경우 — `되돌리기` 있음**

사용자: "git reset --hard origin/main 하라는데 해도 돼?"

> **지금** — 이 폴더에 아직 커밋하지 않은 수정이 3개 파일에 있다.
>
> **실행하면** — 이 폴더의 모든 파일을 GitHub에 올라가 있는 상태로 되돌린다.
>
> **그러면 이렇게 된다** — 그 3개 파일의 수정이 전부 사라진다. 커밋한 적이 없어서 어디에도 사본이 남지 않는다.
>
> **결과값**
> ```
> HEAD is now at 6489974 version 0.2.4
> ```
>
> **되돌리기** — 되돌릴 수 없다. 실행 전에 `git stash`로 수정을 따로 보관해 두면 나중에 꺼낼 수 있다.
